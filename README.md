### #2: Simple p5.js game
<p>Generated using Google Gemini (2.5 Pro) learnt at Google Developer Group meetup (credits to GDG, and speaker Guan Wang for sharing this tip in the session)</p>
<p>It is a Singapore-themed runner game featuring a penguin dodging durians, with a simplified Marina Bay Sands and Singapore Flyer in the background. It is an endless runner and the game continues indefinitely until collision.</p>
<p>This code can be directly pasted into the p5.js Web Editor (https://editor.p5js.org/) or used in any environment that runs p5.js sketches without needing a separate HTML file.</p>
<p><b>How to Play:</b><br/>
Run the Code: Paste this code into the p5.js Web Editor and press the "Play" button.<br/>
Jump: Press the SPACEBAR, the UP ARROW key, or Click the mouse to make the penguin jump.<br/>
Avoid: Dodge the spiky durians rolling towards you.<br/>
Game Over: If the penguin touches a durian, the game ends.<br/>
Restart: Press SPACEBAR or Click again to play again.</p><br/>
